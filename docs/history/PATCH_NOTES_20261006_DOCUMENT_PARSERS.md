# 2026-10-06 문서 파서 통합 패치노트

> 실행 명령과 코드·데이터 경로는 프로젝트 루트 기준입니다.

## 적용 결과

PaddleOCR와 MinerU를 작업폴더의 별도 Python 3.12 환경에 설치하고,
기존 SerDes 블록도와 성능 근거 처리에 연결했습니다. 로컬 서버 재시작 후 정상 상태를 확인했습니다.

## 1. PaddleOCR: 블록도 추출·재생성 보강

- PP-DocLayout-L로 그림 영역을 찾고 기존 architecture 캡션·본문 연결 규칙과 조합합니다.
- 확신도 0.60 이상인 그림 후보만 검토하고, 모델만으로 회로도 의미를 확정하지 않습니다.
- 원본 PDF를 해당 영역으로 렌더링하므로 선·글자·이미지로 구성된 그림을 함께 보존합니다.
- 새 후보는 검토 상태로 생성하며, 기존 원문 검토 결과가 있으면 그 결과를 우선합니다.
- 새 그림 캐시 버전은 v6입니다. 기존 v5 이미지는 계속 읽을 수 있습니다.
- PDF·모델 파일·패키지 버전을 캐시 식별에 포함하고 시간 제한과 실패 로그를 추가했습니다.
- `prepare_serdes_figures.py`에 `--layout auto|paddle|off`, `--cache-namespace`를 추가했습니다.

실제 논문 2건을 비교했습니다.

| 논문 | 확인 및 반영 |
| --- | --- |
| 9062925 | 모델이 여러 그림을 하나의 큰 영역으로 감지하여 캡션에 맞는 기존 객체 추출을 유지. 이전과 같은 크롭 확인 |
| 9830507 | Paddle 그림 영역을 사용. 추가 여백에 앞 그림 캡션의 `coil.`이 섞이는 문제를 발견하고 인접 텍스트를 피하도록 수정. p2 Fig.2 전체 RX/TX 그림을 원문과 대조 후 서비스 이미지에 적용 |

9830507은 그림 위치·크롭을 Codex가 원문과 시각적으로 대조한 기록입니다. 성능 수치 검증을 의미하지 않습니다.
기존 이미지와 비교용 결과는 보존했습니다. 회로의 의미를 추론해 새 도형으로 그리는 기능은 추가하지 않았습니다.

## 2. MinerU: 성능 근거와 검토 신뢰성 개선

- MinerU 4.0.10 Basic ONNX로 PDF의 본문·표·그림·수식을 구조화합니다.
- 수치별 페이지, 정규화 좌표, 캡션, 각주, 표 원문, 측정 조건, PDF SHA256을 보존합니다.
- 다른 문장이나 표 셀의 수치를 하나의 동작점으로 합치지 않습니다.
- 타 논문 수치가 섞인 문장, 불명확한 This Work 열, 병합·누락 셀은 자동 귀속에서 제외합니다.
- 서로 다른 값, 내부 병렬 출력 속도, 실측/모의실험, 전력 범위를 검토 항목으로 표시합니다.
- 기존 파이프라인에 `--extract-mineru PAPER_ID`와 캐시 전용 모드를 추가했습니다.
- SQL에는 별도 `needs_review` 후보로 저장합니다. 기존 확정 성능값은 덮어쓰지 않으며 재실행도 중복 저장하지 않습니다.

실제 데이터에 다음을 적용했습니다.

| papers.id | 논문 번호 | 분석 페이지 | 검토 후보 | 필드별 근거 | 값이 서로 다른 항목 |
| --- | --- | ---: | ---: | ---: | ---: |
| 14 | 11509585 | 4 | 12 | 18 | 1 |
| 50 | 11509525 | 4 | 13 | 21 | 3 |
| 80 | 11509475 | 4 | 13 | 17 | 3 |
| 합계 | 3건 | 12 | 38 | 56 | 7 |

값 차이는 오류 확정이 아니라 동작 조건 차이 또는 추출 오류를 검토하라는 뜻입니다.
예를 들어 11509585의 64 Gb/s 입력과 16개 병렬 4 Gb/s 출력은 서로 다른 범위를 갖습니다.
해당 논문의 0.71 pJ/bit, 45.4 mW, 28 nm도 본문 근거로 추출했습니다.

## 3. SerDes 근거 화면

- 기존 등록 근거와 MinerU 후보를 구분합니다.
- 검토 필요 상태, 원문 페이지 링크, 표 행·열, 측정 조건, 값 차이를 표시합니다.
- 병합 표를 자동 추출에서 제외했을 때 이유와 원문 링크를 제공합니다.
- 처음 16개 이후의 근거도 펼쳐 볼 수 있습니다. DB 근거는 검토 완료 항목부터 최대 80개를 표시하고 제한을 안내합니다.
- PDF가 있으면 기존 등록 근거가 없어도 근거 확인 버튼을 제공합니다.
- 웹 요청에서 모델을 실행하지 않고 준비된 캐시만 읽습니다. 문서 내용은 텍스트로 표시하며 원문 HTML을 실행하지 않습니다.

## 설치·검증

- 전용 런타임: `.runtime/document-parsers/Scripts/python.exe`
- PaddleOCR 3.7.0 / PaddlePaddle 3.3.1 / MinerU 4.0.10 / docvortex 0.5.9
- 실제 CPU 모델 추론 성공. MinerU 첫 4페이지 분석의 모델 처리 시간은 약 24초였으며 전체 시작 시간과는 다릅니다.
- `pip check` 통과.
- SerDes 회귀 테스트 225개, Paddle 테스트 11개, JavaScript 테스트 19개 통과.
- DB에서 후보 38개 모두 `needs_review` 확인. 기존 성능 차트 1,841개 성능점에 이 후보가 포함되지 않는 것을 measurement ID로 검사했습니다.
- 실제 근거 API가 세 논문의 캐시를 읽고 출처 페이지·검토 상태를 반환하는 것을 확인했습니다.
- 로컬 서버 재시작 및 health 정상 확인.

기존 인증 방식과 달라진 테스트 세션 fixture도 현재 account_id/session_version 방식에 맞췄습니다. 인증 기능은 이 작업에서 변경하지 않았습니다.
